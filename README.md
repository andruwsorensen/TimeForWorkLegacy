# Time to Work Legacy

A web application designed to help users manage their workday with timers and a flexible task list. The application features a Workday Timer, a Focus Timer, and a task management system where tasks can be added, edited, completed, and reordered. It also provides a settings menu for customizing default timer values and enables users to optimize their workflow for productivity.

You can access the live site here: [TimeForWork](https://andruwsorensen.github.io/TimeForWorkLegacy/)

---

## Features

- **Workday Timer:** A customizable countdown timer, defaulting to 8 hours, designed to track your daily work.
- **Focus Timer:** A Pomodoro-style timer with a 52-minute work session and a 17-minute break, encouraging productivity and regular rest.
- **Task List:** Create, edit, reorder, delete, and mark tasks as complete. Completed tasks automatically reorder to the bottom.
- **Task Tabs:** Organize tasks into custom categories via draggable tabs for improved organization.
- **Settings Menu:** Adjust the default timer values (hours, minutes) and toggle sound notifications through an easy-to-use settings popup.
- **Responsive UI:** Accessible across devices thanks to mobile-friendly styling.

## Getting Started

### Prerequisites

- Any modern web browser that supports HTML5, CSS3, and JavaScript (ES6).

### Installation

1. **Clone the Repository:**
    ```bash
    git clone https://github.com/andruwsorensen/TimeForWorkLegacy.git
    ```
2. **Navigate to the Project Directory:**
    ```bash
    cd TimeForWorkLegacy
    ```
3. **Launch the App:**
    - Open `index.html` in your preferred web browser.

---

### Usage

- **Timers:** Press "Start" for either timer, "Pause" to suspend, and "Reset" to reset. Click the display to manually edit timer values.
- **Task List:** Add tasks, drag to reorder, edit inline, mark complete via the checkmark, or delete with the trash icon.
- **Tabs:** Click "+" to create a category tab for your tasks and drag tabs to reorganize lists.
- **Settings:** Use the gear icon (top-right) to open settings and modify timer defaults or audio notifications.
